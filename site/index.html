FAQ

Questions, answered

Is it really free?

Yes. WisprFlow is free and open source (MIT). In “On this PC” mode there's nothing to pay for at all. If you choose a cloud provider instead, you pay that provider directly for what you use — usually cents a month.

Windows says “Windows protected your PC”. Is it safe?

That warning appears for any new app that isn't code-signed with a paid certificate. Click More info → Run anyway. The full source code is public, and every installer is built automatically on GitHub from that code.

Do I need an API key?

No. During setup, choose On this PC and download the Base model (142 MB). That's it. API keys are only needed if you'd rather use OpenAI or Groq in the cloud.

How do I get the AI cleanup offline too?

Install Ollama, run ollama pull llama3.2:3b, then in WisprFlow go to Settings → AI cleanup → Self-hosted → Use Ollama. Without it, you get the raw transcript, which is already very good.

Which languages does it support?

Whisper understands 90+ languages, including English, Hindi, Tamil, Spanish, French, German, Japanese and Chinese. It can auto-detect, or you can pick yours in Settings for better speed and accuracy.

What about macOS and Linux?

The app is cross-platform, but ready-made installers are Windows-only for now. On macOS or Linux, clone the repo and run npm install then npm run dev.
