Is SayType free?

Yes. SayType is open source under the MIT licence. On this PC there is nothing to pay; a cloud provider such as Groq or OpenAI bills you for what you use.

Why does Windows warn about SayType?

New apps without a paid code-signing certificate show that warning. Choose More info, then Run anyway. Every installer is built on GitHub from the public source.

Which SayType model should I download?

For English, Base at 142 MB suits most laptops. For Hindi, Telugu, Tamil or Kannada, choose Large v3 Turbo at 574 MB: the small models get those languages wrong.

Does SayType’s AI cleanup work offline?

Yes, with Ollama. Run ollama pull llama3.2:3b, then choose Self-hosted, then Use Ollama under AI cleanup.

Is there a SayType for Mac?

Not as an installer yet. On macOS or Linux, run it from the source code with npm.
